giraffe-bench 🦒

One prompt. Many models. Varying numbers of legs.

“Please create an animation of a giraffe walking through a savannah environment using Three.js”The exact prompt every model received.
🦒

⚠️ This is a Very Serious Benchmark™ (it is not)

One giraffe per model, one prompt, zero rubric. Scoring is by vibes and leg count. Hosted models ran on their vendors' servers; local ones ran on a laptop. Treat it as a field guide, not a leaderboard.

Still, a herd shows patterns a single giraffe can't. Here's what we've spotted so far 👇

  • 🧬 12 models
  • ☁️ 9 hosted
  • 💻 5 local
  • 🪦 3 lost

SmolLM2 360M

💻 local🏷️ smollm2:360m

Refused to write HTML. Its JavaScript imported 16 modules (most of which don't exist), placed one box, then wrote the same zoom handler 19 times. No giraffe was harmed, because none was made.

  • 💻 Local run. MacBook Pro (Apple M2 Pro, 32 GB) through Cherry Studio → Ollama 0.40.4. Effort is Cherry's thinking setting; the level Ollama actually ran is a best guess from each model's default.
  • 😵‍💫 ChatGPT detour. The first reply wasn't obviously an HTML file. Asked "Is this an HTML file I can download?" and received a viewer-wrapped HTML file; the giraffe page was recovered from inside it.
  • 🔧 Fix-it nudge. The first file had an error. One follow-up, "Audit the file - there seems to be an error", got a working version; the page shown is the fixed one.
